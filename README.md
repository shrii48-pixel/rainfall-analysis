# rainfall-analysis
created a analyst data of 1950 to 2017 of the rainfall of India and made a dashboard

🌧️ Rainfall Analysis Dashboard (1950–2017)
📌 Project Overview

This project presents a Rainfall Analysis Dashboard built using Power BI, covering rainfall patterns from 1950 to 2017.
The dashboard provides interactive insights into long-term rainfall trends, seasonal variations, and regional comparisons.

 Objectives

To analyze rainfall patterns over the years (1950–2017).

To identify trends such as increasing or decreasing rainfall.

To visualize seasonal and yearly distribution of rainfall.

To help in climate analysis and resource planning.

 Key Features

📊 Yearly Trend Analysis – visualize rainfall changes across decades.

 Geographical Distribution – compare rainfall across different regions/states (if applicable).

 Seasonal Breakdown – monsoon, winter, summer rainfall variations.

 Interactive Filters & Slicers – select years, seasons, or regions dynamically.

 Comparative Analysis – compare different time periods side by side.

 Tools & Technologies

Power BI (for dashboard development and visualization).

Excel/CSV Dataset containing rainfall data from 1950–2017.

 Dataset Details

Time Period: 1950–2017

Attributes (columns):

Year

Month/Season

Rainfall Amount (mm)

Region/State (if included)

 How to Use

Open the .pbix file in Power BI Desktop.

Use filters/slicers to explore rainfall across years, seasons, and regions.

Hover over visualizations for detailed rainfall values.

 Insights You Can Gain

Long-term rainfall trends (increase/decrease).

Seasonal rainfall contribution over decades.

Variability in rainfall patterns.

Periods of drought or heavy rainfall.
